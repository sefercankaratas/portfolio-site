# Portföy Defteri

Sefer'in aylık portföy takip sitesi. React + Vite ile hazırlandı.

## Yeni ay eklemek

`src/PortfolioDashboard.jsx` dosyasının içindeki `RAW_DATA` objesine yeni ayın verisi eklenir.

## Yerelde çalıştırmak

```
npm install
npm run dev
```

## Canlıya almak

Vercel'e bağlı bir repo — `main` dalına yapılan her push otomatik olarak yayına alınır.
